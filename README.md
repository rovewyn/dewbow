# Dewbow

<p align="center">
  <img src="docs/assets/dewbow-logo.svg" alt="dewbow logo" width="320" />
</p>

Dewbow is an agent-first, self-hosted platform for managing Codex across your machines.

- **Dewbow Core** manages hosts, native conversations, execution configuration snapshots, execution, recovery, and approvals.
- **Dewbow Team** manages agent definitions, teams, members, and bindings to Core sessions.

Each application starts independently and has its own operator Web interface and authentication. Team uses Core's authenticated HTTP API for execution.

Documentation is in [docs/](docs/).
