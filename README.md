# dewbow

<p align="center">
  <img src="docs/assets/dewbow-logo.svg" alt="dewbow logo" width="320" />
</p>

An agent-first, self-hosted service for managing Codex sessions across your machines. Dewbow Core provides execution and recovery; Dewbow Team organizes agent definitions, teams, and member sessions. Each has an independent operator Web interface.

Documentation is in [docs/](docs/).
